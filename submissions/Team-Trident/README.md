## Project Name
Co-Resolve

## Goal / Problem Statement
CO-RESOLVE is an AI-powered crisis-response platform that connects people reporting emergencies with the right volunteers and resources based on their specific needs. It uses AI and intelligent resource matching to identify assistance requirements, prioritize them, and coordinate faster, more effective community response.

## Tech Stack
React.JS, Tailwind CSS, Qdrant, OpenAI Agent SDK

## How to Run (optional)

1. Open the **CO-RESOLVE** web application.
2. Click **“Report a Need”** and select one or more types of assistance required.
3. Enter the crisis details and submit the report.
4. The AI analyzes the request and identifies the required assistance.
5. The system matches the request with suitable volunteers/resources using **Qdrant**.
6. Volunteers can log in, view relevant requests, and respond to cases they can assist with.
